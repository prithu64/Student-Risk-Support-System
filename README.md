# Student Support Risk Prediction System

An ML-powered student support dashboard that predicts academic risk from student indicators and provides supporting factors for review. Predictions are generated by a FastAPI backend, stored in MongoDB, and displayed through a responsive Next.js frontend.

## Dataset

This project uses the [Student Academic Risk Prediction Dataset](https://www.kaggle.com/datasets/arpitsharmaml/student-academic-risk-prediction-dataset) from Kaggle.

## Features

- Student risk prediction using a trained machine-learning pipeline
- Risk categories: `Safe`, `At-Risk`, and `High-Risk`
- Probability distribution for each risk category
- Rule-based contributing factors and support messages
- MongoDB prediction history
- Delete prediction records with custom confirmation modal
- Light and dark themes
- Responsive dashboard layout for desktop and mobile
- FastAPI validation and CORS support

## MongoDB Setup

The application uses this local MongoDB configuration by default:

```text
URI: mongodb://localhost:27017
Database: student_support
Collection: predictions
```

On Windows, start the MongoDB service with PowerShell:

```powershell
Start-Service MongoDB
```

The backend also supports these optional variables in `Backend/.env`:

```env
MONGODB_URI=mongodb://localhost:27017
MONGODB_DATABASE=student_support
MONGODB_COLLECTION=predictions
```

## Backend Setup

From the project root:

```powershell
cd Backend
..\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Start FastAPI:

```powershell
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

The backend will be available at `http://127.0.0.1:8000`.

Interactive API documentation is available at:

```text
http://127.0.0.1:8000/docs
```

## Frontend Setup

From the project root:

```powershell
cd Frontend
npm install
```

Create `Frontend/.env.local` if the backend uses a non-default URL:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

Start Next.js:

```powershell
npm run dev -- --port=3000
```

Open the dashboard at `http://localhost:3000`.

## API Endpoints

### Health check

```text
GET /
```

### Create prediction

```text
POST /predict
```

Example request:

```json
{
  "attendance": 65,
  "study_hours": 1.5,
  "past_failures": 2,
  "assignments_completed_pct": 55,
  "parental_education": "Higher",
  "family_income": "low",
  "extracurricular": "no",
  "internet_access": "yes",
  "previous_grade": 48
}
```

The backend validates the request, runs the saved model, generates the result, saves it to MongoDB, and returns the prediction.

### List prediction history

```text
GET /predictions
```

Returns saved predictions newest first.

### Get one prediction

```text
GET /predictions/{id}
```

### Delete one prediction

```text
DELETE /predictions/{id}
```

## Model Training

The model can be retrained with:

```powershell
cd Backend
..\.venv\Scripts\Activate.ps1
python train_model.py
```

The training script compares Logistic Regression, Random Forest, and XGBoost models, selects the best model by macro F1 score, and saves the final pipeline and supporting files.

The model features are:

- Attendance
- Study hours
- Past failures
- Assignment completion percentage
- Parental education
- Family income
- Extracurricular participation
- Internet access
- Previous grade

## Troubleshooting

### Port 8000 is already in use

Find the process:

```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen
```

Stop the process if it is an old Uvicorn instance, then restart FastAPI.

### MongoDB connection error

Confirm that the MongoDB service is running:

```powershell
Get-Service MongoDB
Start-Service MongoDB
```

### Frontend cannot connect to FastAPI

Confirm that `Frontend/.env.local` contains:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

Restart Next.js after changing environment variables.

### CORS error

Open the frontend using an origin allowed by `Backend/main.py`, such as:

```text
http://localhost:3000
```

Make sure only one frontend dev server is using the expected port.
